# Watch Heaven order schema

Cloud Firestore will store each Cash on Delivery order as one document at `orders/{orderId}`. The document ID is the ERD's `order_id`. The `items` array represents the ERD's `ORDER_ITEMS`. The backend sets `userId` to the signed-in customer's verified Firebase UID.

## Example order

These values are fictional. The `createdAt` string below illustrates the timestamp in JSON. The backend will store it as a Firestore Timestamp generated by the server.

```json
{
  "orderRef": "WH-example-order",
  "userId": "example-firebase-uid",
  "delivery": {
    "recipientName": "Example Customer",
    "phone": "+20 000 000 0000",
    "address": "Example street, Cairo"
  },
  "items": [
    {
      "productId": 101,
      "productName": "Example Watch",
      "unitPriceCents": 4999,
      "quantity": 2,
      "lineTotalCents": 9998
    }
  ],
  "currency": "USD",
  "subtotalCents": 9998,
  "discountCents": 0,
  "totalCents": 9998,
  "paymentMethod": "cod",
  "paymentStatus": "unpaid",
  "status": "pending",
  "createdAt": "2026-01-01T12:00:00Z"
}
```

## How the fields are filled

| Field | Source |
| --- | --- |
| `orderRef` | A customer-facing reference generated by the backend, such as `WH-` followed by the Firestore document ID. |
| `userId` | The verified Firebase UID, which links the order to its owner. |
| `delivery` | The existing checkout form's full name, phone number, and delivery address. Store the phone number as text to preserve the country code and any leading zero. |
| `items` | One entry per product in the order. The backend uses the DummyJSON product ID and saves the purchase-time name and unit price alongside the quantity and line total. |
| `currency` and amounts | The current storefront uses USD. The backend stores whole cents, so `4999` means $49.99. Each line total is unit price times quantity. Subtotal is the sum of line totals, and total is subtotal minus discount. The current checkout uses a zero discount. |
| `paymentMethod`, `paymentStatus`, `status` | Cash on Delivery starts as `cod`, `unpaid`, and `pending`, respectively. |
| `createdAt` | A server-generated Firestore Timestamp. |

The checkout backend will create the order document when a customer places an order. The example above is a reference for that implementation.
